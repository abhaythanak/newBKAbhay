# BackendL Monorepo

This repository contains both the frontend and backend applications for the BackendL project.

## Directory Structure

- `/backend`: Contains the backend application code (Node.js/Express, etc.).
- `/frontend`: Contains the frontend application code (Next.js, React, TailwindCSS, etc.).

## Getting Started

### Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the backend development server:
   ```bash
   npm run dev
   ```

### Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
3. Run the frontend development server:
   ```bash
   npm run dev
   ```

## Repository Management

Both projects are tracked within this single Git repository. You can add, commit, and push changes from the root directory to update both projects simultaneously.
